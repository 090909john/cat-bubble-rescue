# 貓咪小飛俠：泡泡救援隊 🐱🫧🌈

給幼稚園孩子（約 4～6 歲）玩的泡泡救援網頁遊戲。一根手指拖著戴護目鏡、背噴射背包的橘貓飛行，貓咪會自動吹出彩虹泡泡，救援小鳥、花朵和小動物。**沒有敵人子彈、沒有扣血、沒有倒數，不會失敗**；碰到灰色烏雲只會被輕輕彈開，說一聲「哎呀！」。

👉 線上玩：<https://090909john.github.io/cat-bubble-rescue/>

## 特色
- **三個場景、15 關**：花園、天空、海邊，每個場景 5 關，最後一關是大烏雲：吹滿泡泡就變成笑臉彩虹。海邊的大烏雲是終章，天空小鎮會恢復彩虹。
- **學習關卡**：數字氣球、顏色小鳥／小魚、數數看（結算時用大按鈕選答案）、英文字母雲朵、注音雲朵。
- **三段難度**：簡單（找一個目標，數字 1～3）→ 普通（照順序 3 個，數字 1～5）→ 挑戰（照順序 5 個，數字到 10）。
- **內在動機設計（八角框架右腦）**：泡泡工坊（5 種泡泡、6 種顏色）、打扮貓咪（帽子、圍巾、護目鏡）、多種救法（泡泡或直接飛過去抱抱）、自己擺放而且會長大的小花園、被救的動物會回來幫忙、雙人同一台輪流、「給爸媽看」精彩片段回放、驚喜雲朵（星星雨、水果雨、天氣變化、彩虹超級泡泡、神秘訪客台灣黑熊與石虎）。
- **外在獎勵只當紀念**：5 顆星收集條、貼紙簿、動物圖鑑；不排名、不限量、不限時、沒有會消失的獎勵。
- **大人設定**：長按右下角 ⚙️ 3 秒，可調難度、語言（中文／English）、音量、語音提示、遊玩時間提醒，或重設這台平板的進度。

## 技術
- 純前端：HTML Canvas + 原生 JavaScript，沒有外部圖檔，所有圖都是程式畫的（加上系統 emoji）。
- 音效用 WebAudio 即時合成，語音提示用 Web Speech（zh-TW / en-US）。
- PWA：`manifest.webmanifest` + `sw.js` 快取所有檔案，可加到主畫面全螢幕、離線玩。
- 存檔：每台平板各自存在 `localStorage`（花園、貼紙、圖鑑、進度、設定）。
- 內容資料都在 `data/levels.json`、`data/content.json`。

```
index.html  css/style.css  sw.js  manifest.webmanifest
js/core.js    命名空間、工具、多語系
js/store.js   localStorage 存檔
js/audio.js   合成音效與語音
js/art.js     程式繪圖（貓咪、小鳥、花、雲、泡泡、背景）
js/game.js    遊戲核心（拖曳、泡泡、救援、學習規則、大烏雲、驚喜、幫手）
js/garden.js  我的小花園
js/ui.js      各畫面與大人設定
js/main.js    啟動、縮放、服務工作者、遊玩時間提醒
```

## 本機執行與測試
```bash
python3 -m http.server 8000   # 開 http://localhost:8000/
node test/play.js http://127.0.0.1:8000/   # 需要 puppeteer-core 與 Chrome
```
網址加上 `?fast=1` 會加速遊戲並開啟 `window.CBDebug` 除錯介面（`?debug=1` 只開除錯不加速）。
